# Map Data Studio 地图数据工作台

通过桌面界面或 AI 查询高德 POI、采集子点位、补全 Excel 数据和保存景区图片。内置原生 CLI、MCP 与图片浏览器，普通用户无需安装 Node.js、Python 或 Rust。

[下载安装包](https://github.com/FeiXueOpen/map-data-studio/releases/latest) · [详细 AI/MCP 操作指南](docs/AI使用指南.md) · [开发与自动发布](docs/发布与开发.md)

## 功能

- 城市、类型、关键词查询，逐页加载接口可返回的数据；可自定义类型、颜色与手动补点。
- 主点位详情、关联子点位及照片链接采集；保留高德全部原始字段和响应快照。
- 优先获取 AOI 边界，自动查询范围内部点位；无边界或权限不足时手动画多边形兜底。
- 默认杭州标准 34 列景区表，或填写用户的空白 `.xlsx` 模板。
- AI 按来源补全票价、预约、攻略等字段；支持用户制定每列补填规则、类型和字数限制。
- Excel 导出默认不下载图片；明确指定图片点位或映射本地图片字段时保存高德原图，明确提出“联网补图”才触发额外图片搜索。

**AI 研究由连接的 AI 客户端执行，MCP 本身不运行大模型。** 直接点击软件导出按钮只使用已有数据，不自动研究缺项。接口分页、配额和权限可能限制结果，不能承诺穷尽全城全部点位。

## 安装

| 系统 | 下载资源 | 要求 |
| --- | --- | --- |
| Windows | x64 `-setup.exe`，或 `windows-x64.zip` | Windows 10/11 x64，WebView2 |
| Mac Apple Silicon | `aarch64.dmg`，或 `macos-arm64.zip` | M 系列芯片，macOS 13.5+ |
| Mac Intel | `x64.dmg`，或 `macos-x64.zip` | Intel 芯片，macOS 13.5+ |

Windows 运行安装程序；Mac 打开 DMG，将应用拖到 Applications。ZIP 是供 AI/安装脚本使用的完整应用。包较大是因为包含图片浏览器及运行时。Windows 安装程序处理 WebView2，便携 ZIP 需本机已有 WebView2。

当前尚未配置开发者签名和 Apple 公证证书，系统可能要求用户完成首次运行确认。安装脚本不会关闭系统安全功能、移除隔离属性或自动绕过警告。

## 首次设置：自己的三项高德密钥

打开软件 → 左侧“设置”，填写并保存：

| 设置项 | 高德控制台类型 | 用途 |
| --- | --- | --- |
| 高德 Web API Key | **Web 服务** Key | 城市定位、搜索、详情、范围与 AOI |
| 高德 Web JS Key | **Web 端（JS API）** Key | 界面地图显示和交互 |
| JS API 安全密钥 | JS Key 对应的 `securityJsCode` | JS 安全校验，必须与上面的 JS Key 匹配 |

在[高德开放平台控制台](https://console.amap.com/)创建自己的应用和 Key，按平台要求设置域名和接口权限。Web 服务 Key 和 JS Key 不可混用。AOI 可能需要账户单独授权，无权限或无边界时软件退回手动圈选。

发布包不含开发者密钥，密钥保存在本机用户配置目录。不要把密钥放进共享聊天示例、仓库或 Excel。MCP 不提供修改密钥的接口。

设置中还可指定 Excel、图片和其他资源目录，默认系统文档目录 `Map Data Studio/Excel`、`Images`、`Resources`。图片以点位名称建文件夹。图片浏览器代理留空使用系统/环境代理，需要时填写本机实际代理地址。

## AI 接入：CLI + Skill 与可选 MCP

**CLI + Skill 是默认兼容方式。** CLI 提供结构化控制命令，Skill 指导 AI 分页、等待、查证、映射和导出；二者随应用发布，不需要系统 Node.js/Python。MCP 调用同一套工具，是支持客户端的可选增强。

安装计划中的 `cli.command` 是当前电脑的程序绝对路径。AI 可执行：

```sh
"<程序>" skill install --client auto --json
"<程序>" describe --json
"<程序>" doctor --json
"<程序>" status --json
"<程序>" call select_city_by_name --args '{"province":"湖南省","city":"长沙市"}' --wait --json
"<程序>" call start_query --args '{"province":"湖南省","city":"长沙市","categories":["景点"],"autoCollect":false}' --wait --timeout 900 --json
"<程序>" call supplement_pois --args-file /绝对路径/request.json
```

`status/tools/call` 在连接文件尚不存在时会尝试启动桌面应用。长任务在 `call` 后加 `--wait`，或用 `wait <operationId>`，让 CLI 在本机等待，避免 AI 反复轮询。小参数使用 `--args`；大量补全数据使用 `--args-file` 或 `--stdin`，单次上限 16 MiB。Excel、图片只传文件路径。已有 Skill 会先备份。安装后需要让当前 AI 客户端重载 Skill；客户端支持 MCP 时，可继续按下面方式添加连接器。

### “查询列表”和“采集详情”的区别

用户只说“查询长沙景区数据”时，AI 默认让 `start_query` **逐页查询高德列表接口**。这会加载该条件下接口可返回的全部页面，并保留列表响应中的名称、地址、经纬度、评分、照片链接及原始字段；不代表只查询第一页。为了缩短等待时间，这一步不会再逐个请求每个景区详情，也不会递归采集关联子点。

需要完整采集时，应明确说“采集长沙全部景区的详情和关联子点”；AI 才会传入 `autoCollect:true`。如果只要“长沙评分最高的 10 个景区”，推荐流程是先加载列表；列表评分不足时只补候选主点详情，不采集子点；得到评分后筛选 10 条，再按模板补入选项的必要字段并导出。

任务必需字段在高德详情中仍缺失，且用户没有要求“仅高德数据”“缺失留空”或禁止联网时，AI 可以只对最终入选数据联网查证并附来源。联网结果属于 AI 补充，不能伪装成高德字段；“高德评分”等来源绑定字段不得用其他平台数据替代。普通查询不会因为可选字段为空而自动联网，联网补图仍须明确提出。

| 用户表达 | 默认执行方式 |
| --- | --- |
| 查询长沙景区数据 | 逐页加载景区列表，不逐个采集详情和子点 |
| 导出长沙评分最高的 10 个景区 | 加载列表；必要时补候选主点详情后按高德评分筛选，不采集关联子点 |
| 采集长沙全部景区的详情和关联子点 | 对列表中的全部景区执行详情与子点采集，耗时明显更长 |

### 豆包

进入“技能 / 连接器 / 伙伴”（版本间名称可能不同）→ 新建自定义连接器：

- 支持 STDIO 时，命令填软件设置中提供的原生程序绝对路径，参数单独添加 `--mcp-stdio`。
- 只支持 HTTP 时，复制应用设置中的 HTTP 配置。URL 为实际 `http://127.0.0.1:端口/mcp`；Header 名 `Authorization`，值 `Bearer 本机实际控制令牌`。不要粘入 Markdown 链接语法。
- 保存、在当前会话启用连接器，并在技能页导入中文技能 ZIP，再验证 `get_status`。

HTTP 端口和令牌重新开启后会变化，需要更新 HTTP 连接器。客户端与软件应在同一电脑，不能把 127.0.0.1 当作云端服务地址。脚本生成的 stdio 配置在文档目录 `Map Data Studio/Resources/map-data-studio-mcp.json`；仅 HTTP 的版本仍以应用设置中的真实配置为准。不要把本机令牌提交到仓库或发送给远程服务。

### 豆包安装

豆包同样只需发送：“帮我安装 GitHub 上的 FeiXueOpen/map-data-studio”。默认通过 CLI + Skill 使用，不再把连接器配置作为安装成功的前置条件。豆包当前版本能稳定加载 MCP 时，可再按 `doubao-install-plan.json` 增加连接器。

Mac专用入口：下载查看 `scripts/install/install-doubao.sh` 后运行 `bash install-doubao.sh`。Windows专用入口为 `scripts/install/install-doubao.ps1`。支持版本指定、dry-run和不启动应用选项，详见脚本参数。

计划文件位于文档目录 `Map Data Studio/Resources/doubao-install-plan.json`，包含当前电脑的实际程序路径、连接文件路径、命令及独立参数。Mac兼容入口用 `/usr/bin/env`；第一个参数是原生程序路径，其后 `--mcp-stdio`、`--connection-file`、实际文件路径，各填一行，无需额外shell引号。详见[豆包安装与验收](automation/map-data-studio/references/doubao-install.md)。

“连接器运行失败”和“会话没有工具”需分别排查。豆包对话内安装是首选，GUI 是兜底。确认详情页操作清单；必要时重启豆包并新建会话验证。某版本若仍不注入工具，MCP 服务端无法强行把工具塞入模型。

### Codex

## AI 指令使用说明

用户不需要在对话里填写 CLI 参数或工具名称，直接说明业务目标即可。为了减少 AI 猜测和重复调用，一条完整指令最好写清以下内容：

1. **查询范围**：省、市、点位类型和可选关键词，例如“湖南省长沙市、景区、关键词为空”。
2. **需要多少数据**：全部、前 10、前 50，或指定景区名单。
3. **筛选依据**：高德评分、明确的字段条件、用户指定名单，或 AI 综合推荐。评分不能冒充客流，推荐名单不能称为客观排名。
4. **采集深度**：只要列表、补主点详情，还是还要关联子点或景区内部点位。
5. **来源限制**：仅高德原始数据，或允许 AI 对必要缺项联网查证。联网补充会附来源，不会覆盖或冒充高德字段。
6. **Excel 要求**：使用默认 34 列格式还是附件模板；说明目标工作表、列规则、输出目录以及是否允许空值。
7. **图片要求**：不下载图片、保存高德原图，或额外联网补图。联网补图必须明确提出。
8. **完成标准**：要求 AI 报告查询数量、筛选依据、实际导出数量、失败项、剩余缺项和文件路径。

例如，可以把一次任务写成：

> 使用 Map Data Studio 查询湖南省长沙市景区。逐页加载高德可返回的列表，按高德评分从高到低选 10 个独立景区，排除停车场、出入口和附属设施。列表评分缺失时只补候选主点详情，不采集关联子点；详情仍无评分的记录排除并说明。仅使用高德原始数据，不联网补字段，不下载图片。按我提供的 Excel 模板填写，缺失留空，另存新文件。完成后告诉我查询总数、有评分数量、筛选结果、导出行数、缺失字段和保存路径。

### AI 应按什么顺序执行

一般任务采用下面的顺序，避免一开始就采集全城详情：

1. 检查 Map Data Studio 是否已连接，以及当前城市和任务状态。
2. 用户提供 Excel 时，先读取模板表头、示例行、格式和目标空白区域。
3. 一次性设置省、市、类型和关键词，逐页加载高德列表。
4. 检查筛选依据。列表字段足够时直接筛选；评分等必要字段缺失时，只补相关候选主点详情，不递归子点。
5. 得到最终名单和顺序。缺失排序值不能当作 0，也不能为凑够数量伪造数据。
6. 检查最终入选记录的模板必需字段。高德详情仍缺失且用户允许联网时，只研究入选记录的必要缺项并保存来源。
7. 按用户要求处理图片；没有明确要求时不联网补图，普通导出也不隐式下载图片。
8. 导出到新文件，不覆盖模板或已有文件，并报告实际结果。

耗时任务由 CLI 在本机等待，AI 不应反复读取完整状态或重复启动同一任务。用户可以继续询问进度；AI 应说明当前处于列表查询、主点详情、联网查证、图片处理还是 Excel 导出阶段。

### 查询、详情和子点怎么表达

| 推荐表达 | AI 应执行的操作 |
| --- | --- |
| “查询长沙景区数据” | 加载高德列表全部可返回分页，不逐个查询详情 |
| “查询长沙景区，并补入选项详情” | 先查询和筛选，再对最终入选主点查询详情 |
| “只补这些景区的主点详情，不要子点” | 使用限定名单采集详情，保持 `includeChildren:false` |
| “完整采集长沙全部景区详情和关联子点” | 对全部纳入点位采集详情，并显式启用关联子点递归 |
| “查询橘子洲内部点位” | 优先取得 AOI 边界并搜索范围内部点位；没有边界时等待用户圈选 |

“关联子点”和“范围内部点位”不是同一概念。关联子点来自高德详情中的父子关系；范围内部点位来自 AOI 或用户圈选范围搜索，不能宣称是高德官方父子关系，也不能承诺包含地图上的全部标注。

### 评分、Top N 和推荐名单

要求“高德评分最高的 10 个景区”时，AI 应先检查评分是否存在：

- 列表评分完整：直接排序并选前 10。
- 部分评分缺失：仅为缺失候选项补主点详情，然后重新排序。
- 高德列表和详情都没有评分：排除这些记录并报告缺口；不能拿携程、大众点评或百度评分写入“高德评分”。
- 有评分的独立景区不足 10 个：返回实际数量，不用无评分记录补位。

高德评分只代表高德接口在当前查询范围返回的数值，不等于全城绝对排名，也不等于客流量。要求“人流量最多”时，需要具有相同时段、统计单位和景区范围的可靠客流数据；没有可比较数据时，AI 应说明无法形成客观客流排名。用户接受推荐时，可以改为“AI 综合推荐”，但必须列出推荐依据并明确它不是实测排名。

可直接使用以下指令：

> 查询长沙评分最高的 10 个景区。只使用高德评分；先加载列表，评分缺失时只补主点详情，不采集子点。详情仍没有评分就排除并报告，不使用其他平台评分补位。按评分降序导出，不下载图片。

> 从当前高德景区列表中推荐 10 个适合亲子游的景区。允许 AI 根据官方介绍和公开资料综合推荐，逐项给出理由和来源，并明确这不是客流或评分排名。只对入选的 10 条补全模板字段。

### 高德缺失时是否联网补全

联网补全遵循“高德优先、详情其次、入选项兜底”的顺序：

- 用户说“仅高德数据”“不要联网”“缺失留空”时，AI 不联网，任何缺项都保留为空。
- 用户要求“补齐模板”“完整资料”或允许自动兜底时，AI 可在高德详情仍缺失后联网查证。
- 自动兜底只处理最终入选记录和交付必需字段，不研究全城所有候选点位。
- 优先使用景区官网、官方票务、文旅部门和政府公告；每个补充字段必须记录真实来源链接。
- 联网结果属于 AI 补充，不会覆盖高德原始值。无法确认的内容保持为空。
- “高德评分”“高德标识”“高德图片链接”等来源绑定字段不能用其他网站的数据冒充。需要第三方评分时应使用单独列名并注明平台。

允许兜底的示例：

> 查询北京景区并按高德评分选择 10 个。先补入选主点详情，再按默认 34 列格式导出。高德缺失的票价、预约、开放规则和攻略可以联网查证，优先官方来源并附链接；高德评分不得由其他平台替代。未知字段留空并列明，不采集关联子点，不联网补图。

严格原始数据示例：

> 查询南昌市景区并导出高德原始数据。只查询列表和必要的主点详情，禁止联网补字段，禁止联网补图，不采集关联子点。高德没有返回的字段保持空白，并在完成报告中列出。

### 使用自己的 Excel 模板

把 `.xlsx` 模板作为附件发送给 AI，并说明哪一行是表头、从哪一行开始填、需要填写哪个工作表。AI 必须先检查模板，再查询和映射字段。附件需要先保存到运行 Map Data Studio 的电脑，才能把本机绝对路径传给工具；云端附件链接不能直接作为模板路径。

建议逐列说明内容和格式。例如：

> 这是空白城市数据模板，请查询南昌市景区并填写“景区数据”工作表，从第 3 行开始。简介根据官方资料概括，最多 80 字；成人票和学生票只填价格数字；儿童票写“价格 (身高条件)”；老人票写“价格 (年龄条件)”；开放时间统一为 HH:mm-HH:mm，同时保留季节、星期、闭馆和停止入园说明；最佳游览写建议时段和季节，并标明是 AI 建议。只补最终入选点位，所有联网补充附来源。无法确认的字段留空，另存新文件，不覆盖模板。

模板中的示例数据只用于判断格式，不能复制成其他城市的事实。AI 不应覆盖已有内容、公式或合并单元格。默认导出允许保留空值；用户要求所有字段必填时，仍无法查证的内容不会被编造，导出可能被完整性检查阻止。

没有提供模板时，可以要求使用内置杭州标准 34 列景区表：

> 查询杭州市景区，选择高德评分最高的 10 个，使用内置 34 列景区格式导出。仅对入选项补主点详情；允许联网补齐票价、预约、开放时间和攻略并附来源。缺失留空，不采集子点，不下载图片。

### 景区内部点位和子景区

查询某个景区内部设施或子景点前，最好先查询并确认父景区。推荐指令：

> 给当前已加载的“橘子洲风景名胜区”查询内部点位。先核对同名景区的城市和地址，优先使用高德 AOI 边界；没有边界或没有权限时再提示我手动画范围。完成后核对范围上限、失败项和实际数量，按附件模板只导出内部点位，不混入父景区。

手动补录的父点只要有有效 GCJ-02 坐标也能使用范围查询；因为没有高德 POI ID，软件会要求用户手动画范围。范围搜索受高德分页和单次条件上限约束。

### 图片指令

查询、详情和范围采集只保存高德返回的图片链接。Excel 导出默认不下载图片。需要保存高德原图时，应明确指定哪些景区；需要从互联网搜索额外图片时，必须明确说“联网补图”。

只保存高德图片：

> 导出这 10 个景区，并保存其中前 5 个景区的高德原图。不要使用搜索引擎补图。Excel 中记录实际保存路径和失败数量。

额外联网补图：

> 为最终导出的每个景区联网补 3 张图片，使用百度竖图分类，目标比例 3:4，搜索间隔 8 秒。原图保存到设置中的图片目录，以景区名称建文件夹，不裁剪或缩放。遇到安全验证时提示我处理并继续等待；图片不足时报告实际数量和原因。

百度“竖图”是搜索分类，不保证每张图片精确为 3:4。要求精确宽高时可以提供尺寸条件，但原图不符合时会跳过，不会通过裁剪伪造。联网补图使用软件内置浏览器，不要求电脑安装 Chrome；用户关闭浏览器、验证超时或来源不可访问时，任务会报告失败或不足。

### 完成后应让 AI 报告什么

建议在指令末尾加上：

> 完成后报告高德列表数量、补详情数量、关联子点数量、筛选依据、最终入选数量、联网补充字段数量、剩余缺项、图片实际保存数量、失败项和 Excel 绝对路径。不要把任务已启动当作已完成。

AI 只有在导出操作完成并取得实际文件路径后，才能报告成功。查询达到接口分页上限、评分不足、来源无法核实、图片数量不足或部分记录失败时，都应如实列出。

## 开发和自动发布

开发者执行 `npm ci`、`npm run tauri -- dev`，并安装对应系统 Rust/Tauri 构建工具。普通用户下载 Release 即可。

三个版本号同步后推送 `v版本号` 标签，Actions 自动测试并构建 Windows x64、Mac arm64、Mac x64。全部成功才公开 Release，失败时保留草稿供检查，不发布半成品。安装包、便携 ZIP、SHA256、安装脚本、中文技能 ZIP、各平台 Claude Desktop MCPB 与 MCP 清单一起发布。详见[发布与开发](docs/发布与开发.md)。
