# POI 分类目录

`poi-types.json` 提取自高德开放平台官方 POI 分类编码表，共 915 项，用于自定义类型选择。

来源：https://lbs.amap.com/api/webservice/download
下载：https://a.amap.com/lbs/static/code_resource/Amap_poicode.zip
官方表版本：V1.06_20230208；下载页标注更新时间：2023-10-13。
获取日期：2026-10-09。

目录保存编码和中文大类、中类、小类；实际点位数据仍通过官方在线 API 查询。目录后续更新时应替换数据并检查已保存的自定义编码。
